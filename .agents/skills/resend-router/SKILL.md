# Resend Skills Router

Resend email skills are available from upstream and NOT vendored locally.

## Install

```bash
npx skills add resend/resend-skills
```

This installs: resend, resend-cli, and related email skills.

## Usage

After installation, skills are available in `.agents/skills/resend*/` and load automatically when their triggers match.

# Marketing Skills Router

Marketing/growth skills (by coreyhaines31) are available from upstream and NOT vendored locally.

## Install

```bash
npx skills add coreyhaines31/marketingskills
```

This installs 55+ marketing skills: ad-creative, ads, ai-seo, cold-email, competitor-profiling, competitors, content-strategy, copywriting, cro, customer-research, emails, launch, marketing-plan, offers, onboarding, pricing, product-marketing, programmatic-seo, prospecting, revops, sales-enablement, schema, seo-audit, signup, site-architecture, sms, social, and more.

## Usage

After installation, skills are available in `.agents/skills/<name>/` and load automatically when their triggers match.

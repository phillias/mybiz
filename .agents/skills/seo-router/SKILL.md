# SEO Skills Router

SEO skills (by AgriciDaniel) are available from upstream and NOT vendored locally.

## Install

```bash
npx skills add agricidaniel/claude-seo
```

This installs all 25+ SEO skills: seo, seo-audit, seo-backlinks, seo-cluster, seo-competitor-pages, seo-content, seo-content-brief, seo-dataforseo, seo-drift, seo-ecommerce, seo-flow, seo-geo, seo-google, seo-hreflang, seo-image-gen, seo-images, seo-local, seo-maps, seo-page, seo-plan, seo-programmatic, seo-schema, seo-sitemap, seo-sxo, seo-technical.

## Usage

After installation, skills are available in `.agents/skills/seo-*/` and load automatically when their triggers match.
